# Little Ant 1.0 discovery archive

This directory preserves the complete pre-consolidation discovery record as it
stood on 2026-07-29. Its files contain proposals, corrections, repeated
summaries, unresolved questions, regression analysis, and chronological
session evidence.

The archive is intentionally non-normative. Use the compact canonical index at
[`spec/little-ant-1.0.md`](../../little-ant-1.0.md) for current 1.0 behavior.
Use [`traceability.md`](../traceability.md) to find the current disposition of
historical material.

The archived entry point is
[`00-conceptual-design-record-index.md`](00-conceptual-design-record-index.md).
Its old precedence rules describe the discovery process and no longer govern
the product specification.

Historical files must remain byte-for-byte stable except for an explicitly
documented archival repair. Current corrections belong in the compact
canonical chapters and the traceability register.
