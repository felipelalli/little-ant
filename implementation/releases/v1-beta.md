# Little Ant 1.0 beta backlog

Status: **planned after alpha feedback**

The beta owns every remaining 1.0 obligation that does not block safe daily
use of the dumb alpha.

## Required beta work

- Generalize migration to every event type delivered by signed `v0.1.0`,
  nonempty v1 targets, reviewed merges, typed repair choices, and handle
  conflicts.
- Replace the alpha's explicit staged flags with the complete durable-plan,
  guided preview/consent, stable allocation-reuse, inspection, and REPL route
  required by the final migration contract.
- Complete Wait activation and follow-up, Delegation strategy and
  reconciliation, message editing and delivery, effect recovery,
  compensation, and duplicate-risk handling.
- Complete semantic update, merge, supersede, external editor, Pack untrust,
  Raw/source reconciliation, and every translation route.
- Stabilize recurrence, habits, scheduled commitments, and other temporal
  paths currently exposed for experimental use.
- Complete Calendar adoption, reconciliation, and reviewed write-back.
- Stabilize Packs, vault, OAuth, provider imports, source cleanup, exporters,
  and their recovery surfaces.
- Implement the loopback-only `local_web` UIAdapter.
- Implement powered-up mode and a compact v1 Skill as attributed mirrors of
  the canonical dumb envelopes.
- Prove required CLI, REPL, powered-up, Skill, and local-web parity; update the
  coverage register from executable evidence for all 65 canonical flows.
- Run the synthetic week, parameter sweeps, complete migration regression,
  release audit, and public prerelease packaging.

## Desirable, non-blocking simplification review

After real alpha use, draft an RFC that inventories actual command and
subsystem use, identifies accidental complexity, and compares concrete ways
to move capabilities out of the core or reduce types, commands, and tests.
Packs, vault, effects, connectors, or any other subsystem must not be removed
or redesigned merely because the RFC exists.

The RFC and every proposed simplification require human discussion, debate,
and explicit approval before either the specification or implementation is
changed. Completing or accepting that RFC is not a beta promotion gate.
