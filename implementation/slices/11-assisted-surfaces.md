# S11 — Assisted surfaces and release closure

Status: **planned**

## Outcome

Add bounded assistance without a second product: powered-up REPL, the v1 Skill,
factory personality, local-web rendering, and complete paired replay across all
65 canonical flows.

## Canonical flow rows owned

- Contextual personality
- Honest-answer assistance
- Local web UIAdapter
- Powered-up paired replay
- Skill and local-web mirror

Generate every owning-row reference plus UX-002..004, UX-016..018,
UX-033..039, UX-043..044, UX-059..065, UX-086..087, UX-196,
UX-269, the personality catalog, the complete screen catalog surface mapping,
SCN-UI-001, SCN-FED-004, SCN-UIA-001, and every earlier flow row that requires
paired assisted evidence.

## Work

1. Validate the configured powered-up executable at startup through stdin-only
   structured challenge/response; fail before the REPL starts when unsuitable.
2. Implement a strict proposal schema, bounded prompt context, tolerant outer
   text extraction, provenance, confidence, validation, cancellation, and
   fallback to the exact dumb route.
3. Permit only the assisted deltas named by canonical rules: visible suggested
   defaults, bounded preclassification/preordering, attributed text or
   decomposition proposals, title translation, and personality paraphrase.
4. Replace the historical v0 Skill with a compact v1 operator that queries
   sparse CLI results, invokes only canonical commands/actions, and follows the
   same envelopes rather than restating the spec.
5. Complete local-web rendering from the same InteractionEnvelope with
   loopback/session/revision protection and no independent grammar.
6. Replay every canonical flow in dumb mode, then every required powered-up,
   Skill, and local-web pair. Run the synthetic week, authorized shadow-day
   protocol when data access is separately approved, parameter sweeps,
   migration suite, and release audit.

## Gate

- disabling or failing the model returns the exact dumb product with no lost
  capability;
- no assisted output bypasses a preview, allocates identity, records human
  judgment, changes action order, or invents a command;
- powered-up prompts receive sparse bounded context and never secret material;
- the Skill contains no shadow lifecycle, command alias, ranking rule, or
  copied screen state machine;
- all 65 flow rows move to `verified` only from recorded executable evidence;
- README claims, packaged standard content, command help, schema registry,
  v0 matrix, and the shipped binaries agree with the passing implementation.
